# КиберЧекап

Бэкенд для лендинга услуги по кибербезопасности. Принимает заявки с формы, ведёт их
в CRM, шлёт клиенту цепочку писем. Плюс подсказка кода ОКВЭД: человек пишет, чем
занимается, своими словами, а поле подставляет код.

Стек: Python 3.12, FastAPI, PostgreSQL 16 с pgvector, SQLAlchemy 2.0, Alembic,
sentence-transformers (multilingual-e5-base), Docker Compose.


# Откуда взялся проект

Делал по заказу для компании.
Требования: лендинг с возможностью отправки заявки и CRM для управления этими заявками (отслеживание статуса и отправка писем по воронке, сделанной компанией).
Также был реализован умный поиск кодов ОКВЭД с помощью модели intfloat/multilingual-e5-base, но в итоге заказчики от неё отказались, это фичу я уже вернул позже, чтобы выложить в гитхаб. 
Проект дошел до прода, но в итоге он закрылся, поэтому я выложил его в свой гитхаб. 
Писался исключительно на локальной машине, так как это был мой первый рабочий проект, и я ещё не привык работать с гитом на тот момент, но сейчас такой проблемы нет.
Дизайн был сделан с помощью Claude Design, после по требованию заказчика был перенесен на Tilda.

## Запуск

```bash
docker compose up -d          # postgres с pgvector

cd backend
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
alembic upgrade head          # схема
python scripts/load_okved.py  # справочник, качает модель 1,1 гб
uvicorn main:app --port 8013
```

`/setup` почта и логин админа, `/admin` заявки.

Лендинг отдельно: `python3 -m http.server 8090` из `frontend`.
